# 주간 마케팅 실행 성과 페이지

강의하는아이들 배곧수학학원(김일동 원장 · 경기 시흥시 배곧동)의 **주간 공개 발행 성과**를 모아 보여 주는 정적 페이지입니다.
GitHub Pages(main 브랜치 루트)에서 서빙되며, 주소는 **https://ildong0311-dot.github.io** 입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면(디자인·필터·카드 렌더링). 손댈 일이 거의 없습니다. |
| `data.json` | **매주 갱신하는 파일.** 이번 주 공개 발행분 전체가 여기에 들어 있습니다. |

`index.html`은 `data.json`을 읽어서 화면을 그립니다. 그래서 매주 갱신할 때는 **`data.json`만 고치고 커밋**하면 됩니다.

## data.json 갱신 규칙 (매주 화요일)

1. `period_label`, `updated_at` 을 이번 주 범위와 집계 시각으로 바꿉니다.
   - 예: `"2026. 11. 23(월) ~ 11. 29(일) 11:30 현재 · 공개 발행분만"`
2. `items` 배열에 이번 주 **실제로 전체공개 발행된 건**을 최신순(날짜 내림차순, 같은 날은 시각 내림차순)으로 넣습니다.
   - `date`: `YYYY-MM-DD`, `dow`: 요일 한 글자(`월`~`일`)
   - `time`: 게시 시각 `HH:MM` (플랫폼에서 확인한 시각. 확인이 어려운 채널은 빈 문자열)
   - `cat`: `blog` | `yt` | `tt` | `clip` | `place` | `home`
   - `ch`: 채널 표기 (예: `네이버 블로그 · ildong94(공식)`), `title`: 실제 게시 제목, `sub`: 한 줄 부제
   - `url`: 실제 공개 링크
3. `stats`(전체 공개 건수 / 블로그 편수 / 숏폼 편수), `summary`(채널별 편수), `filters`(칩별 건수)를 `items`와 일치하도록 다시 계산합니다.
   - 전체 = items 개수, 숏폼 = `yt` + `tt` + `clip`
   - 칩: 전체 / 블로그(blog) / 유튜브 쇼츠(yt) / 틱톡·클립(tt+clip) / 플레이스·홈페이지(place+home)
4. 같은 영상을 유튜브·틱톡·클립에 각각 올린 건은 **채널별로 1건씩** 셉니다. (화면에도 안내 문구가 있습니다.)

- 학원명은 **`강의하는아이들 배곧수학학원`** 만 사용합니다. `배곧서울대 캠퍼스`, `서울대` 표기는 넣지 않습니다.
