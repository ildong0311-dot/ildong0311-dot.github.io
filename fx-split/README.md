# 환율 분할매매 (시뮬레이터)

달러·엔·유로를 정해진 간격으로 나눠 사고(분할 매수), 차수별로 목표 수익에 도달하면 파는(분할 매도) 자동매매 앱입니다.
지금은 **가상 체결** 버전이며 실제 주문은 나가지 않습니다. 데이터는 브라우저(localStorage)에만 저장됩니다.

| 파일 | 역할 |
| --- | --- |
| `engine.js` | 매매 엔진(전략·체결·손익 계산). 화면과 분리되어 있어 실거래 연동 시 체결 부분만 교체 |
| `app.js` | 화면 (홈 / 바로환전 / 전략추가 / 분할현황 / 세부거래내역 / 설정) |
| `engine.test.js` | 엔진 테스트 — `node fx-split/engine.test.js` |

## 전략 규칙
- 1차수: 예약환전은 살때 환율 ≤ 1차수 예약가, 즉시환전은 바로 매수
- n차수: 살때 환율 ≤ 직전 차수 매수가 − 매수간격 (한 틱에 한 차수)
- 매도: 각 차수의 팔때 환율 ≥ 그 차수 매수가 + 매도간격
- 재매수: 판 차수를 다시 사는 것. 예전 매수가 이하에서만, 매도가 일어난 틱에는 사지 않음
- 확정손익 = 매도금액 − 그 차수의 실제 매입원가 (보유분은 평가손익으로 따로)
